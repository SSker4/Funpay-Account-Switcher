## ✨ Возможности

- 🔁 Быстрое переключение аккаунтов
- 👤 Удобный список профилей
- ⚡ Экономия времени
- 🧩 Простой интерфейс
- 🛠️ Подходит для активной работы с FunPay

---

## 🧠 Зачем?

Когда аккаунтов несколько, постоянный вход и выход превращается в браузерный квест.  
**FAS** делает всё проще: выбрал аккаунт → переключился → работаешь дальше.
